# Legacy XLS Regression Fixtures

These workbooks are independently generated by `generate.py` using
[xlwt 1.3.0](https://github.com/python-excel/xlwt) and read back for verification
with [xlrd 2.0.2](https://github.com/python-excel/xlrd). All data is synthetic; no
user files are included. The app and Swift tests do not require Python at runtime.
Chinese strings in the fixtures and test assertions are intentional test data
for Unicode import, editing, and export.

- `business-export.xls`: three worksheets, Chinese and English text, emoji, long
  text spanning SST/CONTINUE records, merged headers, fonts, palette colors,
  borders, alignment, row heights, column widths, hidden items, frozen panes,
  dates, numbers, and booleans. Includes a `1+2` formula; xlwt does not evaluate
  formulas, so its cache and the imported cell are empty. The importer must warn
  that formulas are imported using cached values only.
- `dates-1904.xls`: the 1904 date system. Date serial 44850 should normalize to
  46312, while the ordinary number 42.5 must remain unchanged.
- `layout-and-tab-order.xls`: worksheet tab order differs from physical substream
  order. Covers the default palette, default row height, row and column styles,
  unfrozen split panes, and the U+0080 character in compressed Unicode.
- `formula-caches.xls`: numeric, boolean, error, empty-string, and Unicode-string
  caches are explicitly populated in formula records generated by xlwt, then
  verified with xlrd. Tests confirm that import does not trigger recalculation.

To regenerate the fixtures, install the pinned versions above in an isolated
virtual environment and run `generate.py`. The script uses an independent reader
to assert key values and formatting. Swift's `XLSTests` additionally verify
import, editing, XLSX export, and reopening.
